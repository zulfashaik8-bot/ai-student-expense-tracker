# AI Student Expense Tracker

A responsive student expense tracking web app built with HTML, CSS, and JavaScript.

## Features
- Add expenses with name, amount, category, date, and payment method
- Monthly budget, spending, remaining balance, and transaction summary
- Search and delete expenses
- Doughnut chart showing spending by category
- Rule-based smart saving tips (no AI API key required)
- Light/dark theme
- Saves data in browser local storage

## Run locally
1. Download and extract the project ZIP.
2. Open `index.html` in a web browser.
3. Internet access is needed for the Chart.js CDN chart; the rest of the app works locally.

## Publish with GitHub Pages
1. Create a public repository named `ai-student-expense-tracker`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for deployment. Your site URL will typically be `https://YOUR-USERNAME.github.io/ai-student-expense-tracker/`.

## Note
This student project provides locally generated, rule-based insights rather than connecting to an external AI model. Expense data is stored in the current browser only; it is not synced between devices.
